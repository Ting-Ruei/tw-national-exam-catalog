# A2.1 — 把圖放到模型面前之後，天花板就移動了（D13 的答案）

**一句話**：同一組 47 題、同一批人工修正，**只看文字**天花板是 41%；
**看那一頁的圖**之後，`occamy` 在「文字推得出」的欄位上到達 **78.4%**，
而**同一個提示詞但不給圖**（負對照）掉回 **27.8%**——**進步是圖带來的，不是提示詞。**

---

## 1. 這一輪在問什麼

`a2-model-comparison.md` 量到：設計者的 90 個欄位改動裡，**53 個（58.9%）的資訊不在模型看到的字串裡**
（`罕 疾病`→`罕見疾病`、`3ࠕ間Әཊ使`→`3年間不行使`）。純文字上限 41.1%。

A2.1 就是下一步，也是 **D13 真正要的比較**：

> **如果模型看得到那一頁，天花板會不會移動？**

## 2. 方法（刻意選最便宜的那一種）

- 用**生產線自己的** `three_way.analyse_items` 分題、取每一題的頁碼（**0.2 秒／卷**，~16 頁）。
  —— 不用第二套切題器，否則「這題在第幾頁」會有兩個答案。
- 給模型的是**整頁的圖**（150 dpi PNG），不是裁好的小圖。
  **這是最大的裁切**：答案在頁上哪裡都包含得到。
  → **如果給整頁都不動，給更小的裁切也不會動；如果會動，裁切是精修、不是前提。**
- 為什麼給整頁而不是選項裁圖：A2.1 要測的缺陷類別是**題幹裡的字**（被吃掉的字、被壓平的上下標），
  不是圖形的範圍。
- 產物：`compare_models_vision.py`，輸出 schema 與 `compare_models.py` 完全相同
  → `split_by_ceiling.py`、`build_compare_page.py` **原封不動**讀得懂。

## 3. 【負對照】進步是圖，不是提示詞

視覺提示詞比文字提示詞多講了「以圖為準、看得到就照圖改」。若不控制這個，
47.8% 可能是**提示詞**造成的，不是圖。所以有一個**同提示詞、不附圖**的開關 `--no-image`：

| 模型 | 提示詞 | **有圖** | 無圖 | 差 |
|---|---|---|---|---|
| `ornith-1.5-mtplx-35b` | 視覺版 | **47.8%** | **18.9%** | +28.9 |
| `occamy-1.0-6bit-xl-mlx` | 視覺版 | **53.3%** | **27.8%** | +25.5 |

→ **提示詞幾乎沒有貢獻（18.9% ≈ 純文字版 20.0%）；圖貢獻了絕大部分。**

## 4. 天花板真的移動了

| | 純文字 | **看那一頁的圖** |
|---|---|---|
| 可達欄位（37） | occamy 29.7%／ornith 21.6% | **occamy 78.4%**／ornith 64.9% |
| **不可達欄位（53）** | occamy 3.8%／ornith 18.9% | **occamy 35.8%**／ornith 35.8% |
| 整體 | occamy 14.4%／ornith 20.0% | **occamy 53.3%**／ornith 47.8% |

**兩個關鍵讀數**：

1. **「不可達」不再是 0。** 53 個欄位裡，兩個模型都攻下 **19 個（35.8%）**。
   這些正是「文字裡沒有」的字——**它們現在在圖上被讀出來了**。
2. **可達欄位被推到接近八成（occamy 78.4%）。** 這說明：**有圖之後，剩下的錯主要是判斷錯，不是看不到。**

> **所以 D13 的答案不是「哪個模型比較好」，是「一定要餵圖」。**
> 只給文字的比較會系統性低估每一個模型，而且低估的幅度**正好是設計者最在意的那一類錯**。

## 5. 兩個模型看圖之後仍然不同

| | `occamy-6bit`（18130） | `ornith-mtplx-35b`（18120） |
|---|---|---|
| 有圖整體 | **53.3%** | 47.8% |
| 有圖可達 | **78.4%** | 64.9% |
| 有圖不可達 | 35.8% | 35.8% |
| 多改（有圖） | 9–10 | **8** |
| 多改（純文字） | 9／12 | **5** |
| 純文字可達 | **29.7%** | 21.6% |
| 純文字不可達 | 3.8% | **18.9%** |

**occamy 在有圖之後全面領先，但它多改的次數一直比 ornith 多**（9 vs 8；純文字 12 vs 5）。
**多改是這一條線最貴的錯**——設計者要的是「不亂動」。
→ **建議：`occamy` 當主力（有圖時準確高），`ornith` 當第二意見／守門（它比較不亂動）。**
最終定案應等 `occamy-abliterated`（18131 down）也測完。

## 6. 誠實的邊界

1. **47 題、n 小**；兩個模型的差距（53.3% vs 47.8%）**在這個 n 下不是穩定的排序**。
2. **不可達欄位的 35.8% 是「還有 64.2% 沒攻下」**——不是天花板已經到頂。
   → 下一輪該看那 34 個失敗的欄位：是圖太小（150 dpi）？整頁太大找不到位置？還是模型真的讀不出？
3. **只測了 2 個模型**；`occamy-abliterated`（18131 down）與 `Splash`（8088 down）未測。
4. **只給整頁**，沒試「裁到題目 band」或「放大 300 dpi」。整頁是**下界**，不是上界。
5. **沒有測多圖／跨頁題**。
6. **`occamy` 的多改（9–10 次）沒有逐筆看**，只知道次數。
