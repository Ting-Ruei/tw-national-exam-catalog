## 四、效果：新科目 vs 舊科目（同樣的偵測規則）

| 指標 | 舊（藥師＋醫檢） | 新（放射/物治/醫師） |
|---|---|---|
| 題數 | 33,150 | 45,540 |
| 選項不是 4 個 | 0.03% | 0.22% |
| 四個選項全空 | 0.79% | **0.14%（低 5.6×）** |
| 沒有答案 | 0.00% | 0.00% |
| `option-shape` | 0.82% | **0.36%** |
| `substituted-ideograph`（`⻑`） | 0.20% | 0.28% |
| `dangling-answer` | 0.03% | 0.22% |
| `lost-glyph` | 0.13% | 0.10% |
| `empty-option` | 0.04% | 0.00% |

**讀法**：

- 「四個選項全空」在舊科目 0.79%、新科目 0.14%。舊的那 261 題集中在**化學結構題**
  （藥師的藥物化學），新科目較少。這是**科目性質**，不是新科目品質較好。
- `substituted-ideograph` 新科目 0.28% 略高——`⻑` 在醫師科目（`年⻑者`）本來就更常見。
  這條規則在**沒看過的新科目上仍然成立**，這是它值得存在的理由。
- **沒有一條規則在新科目上爆量。** `option-shape` 甚至下降。

### 一個已知缺陷（本次擴大時發現，未修）

`qbr/src/qbr/package.py:210` 把 `has_visual_asset` **寫死成 `False`**：

```python
"visual_profile": {"has_visual_asset": False, ...}
```

所以 78,690 題**全部**都是 `has_visual_asset=False`，包含 261+65 題選項其實是化學結構圖的題目。
這使得「這題有沒有圖」在下游無法從這個欄位判斷，也讓 `disputes.py` 的
`empty-option` 抑制邏輯（251/274 是對的）失去依據。

**修它的前提**是先確認圖片綁定在哪一層做（`crop_run_figures` 或 exporter），
否則會變成「在錯的樓層加一個欄位」。這次先記錄，不動。
