# AI 第一輪審查：量測、結論與建議

> 這份文件回答 Task 21 的問題：**能不能讓 AI 先看一遍，人只看它挑出來的？**
>
> 答案是用數字給的。結論是**不行**——但過程中找到三類可以確定的缺陷，那些才是該做的事。
> 全部量測可重跑（腳本與原始輸出列在最後）。

## 一句話

**重讀的旗標精確率只有 12–16%。** 單引擎旗標 42 題裡只有 5 題是你真的會 block 的；
兩引擎都旗標 19 題裡只有 3 題。若把它當 triage 佇列，**每 6.3 題才 1 題有用**。

## 命題（用資料算出來的）

| | 數字 |
|---|---|
| 線上題數 | 33,150 |
| 你已審 | 144 題（0.43%） |
| 其中 block | 11 筆事件 / 10 題（7.6% of 已審） |
| 以每題 8 秒計，審完全庫 | **74 小時** |
| 決定性層（`disputes`）抓到你的 block | **0 / 10** |
| 決定性層全庫覆蓋 | 77 題（0.23%）——它只看結構 |

決定性層幾乎不做事，因為它檢查的是**結構**（選項數、答案對得上、字形遺失）。
你 block 的是**內容**。這就是為什麼 Task 21 看起來需要模型。

## 實驗設計

用**你自己的決定當標籤**（block = 你拒絕、accept = 你放行），重讀從未看到標籤。

1. 對每一題，取其「自己的題號到下一個題號」的 row band（**跨頁**，Q49 的表格在下一頁頂端）。
2. 以 200 dpi 裁切，stitch 成一張圖。
3. 模型**只做轉錄**，不做判斷。prompt 明講「不要修正你認為是錯的字」。
4. 轉錄結果與管線的讀法**逐字元 diff**，在本地做，確定性。

比較式：NFKC（折疊 Kangxi radicals 與相容表意字）+ 去空白 + 折 LaTeX 上下標。
**不折** CJK Radicals Supplement——因為那正是要看的差異。

## 結果

| | block | accept | 召回 | 誤報 | 精確率 |
|---|---|---|---|---|---|
| 單引擎（ornith） | 5 / 9 | 37 / 130 | 56% | 28% | **12%** |
| 兩引擎都要旗標 | 3 / 9 | 16 / 130 | 33% | 12% | **16%** |

**兩引擎一致沒有救回精確率**，因為失敗模式不是「不穩定」，是**兩邊都對、管線也對**：
模型把 `tranylcypromine` 讀成 `tranilcypromine`（兩引擎都可能），
或把 `那一種` 讀成 `哪一種`、`製備` 讀成 `製造`、`所記載` 讀成 `所說`。

**一個讀錯的模型與一個真的錯字，在單次轉錄裡無法區分。** 這是根本限制，不是調參。

已接受題被旗標的 37 題，diff 的內容幾乎都是這一類。**沒有人的標籤，這些「差異」不能分辨。**

### 樣本量要誠實講

block 只有 **9 題**。9 題的召回率，差一題就是 11 個百分點。上面的百分比**不足以支撐**
任何「A 方法比 B 方法好」的結論；能支撐的只有一件事：**旗標大部分是噪音，因為
誤報的內容被逐一檢視過了**。

## 但實驗找到了三類可以確定的缺陷

重讀的價值不在「挑出可疑的」，而在於它**證明了一件事可以確定的地方**。以下每一類都在
兩引擎上一致，而且可重複：

| 類別 | 內容 | 處置 |
|---|---|---|
| **1. 上下標** | `Cp` 應為 `Cₚ`、`-kt` 應為 `⁻ᵏᵗ` | **已修**（`891441d`）——幾何可測，不需模型 |
| **2. 取代字** | `⻑`(U+2ED1) 應為 `長`(U+9577)；`⺠`、`⻄` | **已修**（`724a363`）——NFKC 折不回，全庫 65 題 |
| **3. 選項內容不在管線裡** | 紙本有 `Cumulative drug release (%)`、`AUC=Cp0/k10`，管線是空的 | **尚未修**（見下） |

**1 與 2 都不是模型找到的，是量測找到的。** 模型只是被用來對回紙本、確認我的量測正確
（「紙本印的是長還是⻑？」）。這是模型在本專案已被證明唯一可靠的工作：**回答關於它看到的圖的
封閉問題**。

### 第 3 類：`empty-option` 的 251/23 需要重新量

`disputes.py` 記載：「274 個空選項裡 251 個是對的，因為選項**就是**圖」。這是為什麼
`option_images` 會抑制 `empty-option`。

`115020:305:0403` Q62 是那 23 個的候選：四個選項 A–D 文字全空、紙本上 `A.` 到 `D.` 之間
有大間隔（y 227→374），而兩引擎重讀都讀到 `AUC=Cp0/k10` 這種內容。你把它判為 block。

→ **建議**：對「全空選項」這 274 題，用重讀量一次「紙本到底有沒有內容」。
這比全面 triage 小得多（274 題 vs 33,150 題），而且答案是可數的。
